ШРИФТИ СТАТИЧНОЇ ВЕРСІЇ ДЛЯ GITHUB PAGES

Файли шрифтів підключаються через assets/fonts.css. PHP для цього не потрібен.
Підтримувані файли в цій збірці: UAFSans-*.ttf та Volja-*.otf.

УВАГА: перед завантаженням до публічного GitHub-репозиторію перевірте ліцензію
та право на публічне розміщення цих файлів. GitHub Pages віддає файли шрифтів
відвідувачам сайту, навіть якщо репозиторій приватний.
Якщо право на публікацію не підтверджене, видаліть файли шрифтів і залиште
assets/fonts.css як шаблон або приберіть його підключення: інтерфейс матиме
системні sans-serif шрифти.
