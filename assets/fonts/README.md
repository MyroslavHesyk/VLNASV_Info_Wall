# Підключення офіційних шрифтів ЗСУ

Зображення з прикладами UAF Sans / Volja **не є файлами шрифтів**. ZIP не включає невідомі або неавторизовані копії.

1. Отримайте офіційні WOFF2 із дозволом на розміщення на сайті.
2. Додайте `UAFSans-Regular.woff2`, `UAFSans-Medium.woff2`, `UAFSans-Semibold.woff2`, `UAFSans-Bold.woff2` сюди.
3. У `assets/fonts.css` замініть `src:local(...)` на наведені URL відповідного начерку; не змінюйте `font-weight`.
4. Запуште в репозиторій. Файли WOFF2 тепер роздаватимуться GitHub Pages.
5. У Developer Tools / Network перевірте статус 200 для всіх шрифтів.

UAF Sans застосовується до всього інтерфейсу; Volja — не використовується для дрібних текстів.
