# Інформаційний екран Військового ліцею — статична версія

Ця збірка підготовлена для **GitHub Pages**. У проєкті немає PHP, бази даних або серверного процесу: сторінка працює на HTML, CSS і JavaScript у браузері.

## Що збережено

- Інтерфейс, стилі, карта України та позначка місця розташування ліцею.
- Червоний і жовтий рівні, окреме зіставлення районів, включно з перейменованими районами.
- Локальний статус Шептицького району та верхня інформаційна стрічка.
- Поточна погода й прогноз на п’ять днів.
- Дні народження з поділом на працівників і ліцеїстів, пагінація списку.
- Розпорядок дня для буднів, суботи й неділі.
- Хвилина мовчання та демонстраційні режими.
- Збереження часу першого виявлення тривоги в `sessionStorage` у межах вкладки.

## Як оприлюднити на GitHub Pages

1. Створіть репозиторій GitHub.
2. Завантажте **вміст цієї папки** в корінь репозиторію — файл `index.html` має лежати саме в корені вибраної гілки/папки публікації.
3. Відкрийте **Settings → Pages**.
4. У блоці **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Після завершення публікації GitHub покаже адресу сторінки. Для звичайного проєктного репозиторію адреса має вигляд `https://USERNAME.github.io/REPOSITORY/`.

Файл `.nojekyll` вимикає автоматичну обробку Jekyll для цієї статичної збірки.

## Локальна перевірка

Не відкривайте `index.html` подвійним кліком через `file://`: браузер обмежує `fetch()` для локальних файлів. Запустіть простий локальний HTTP-сервер у корені папки. Наприклад, якщо встановлено Python:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000/`. Для демонстрації станів використовуйте параметри:

- `?preview=yellow` — жовтий рівень;
- `?preview=alarm` — червоний рівень;
- `?preview=clear` — локально тривоги немає;
- `?preview=silence` — тестова хвилина мовчання на 60 секунд.

Демонстраційні режими не звертаються до API тривог і не є сигналами реальної небезпеки.

## Налаштування

### Основні параметри й розклад

Файл `assets/config.js` містить:

- назву та місце розташування;
- координати для погоди й маркера на карті;
- часовий пояс;
- ключові фрагменти назв локального району;
- URL API;
- інтервали оновлення;
- розклад на будні, суботу й неділю.

Змінюйте ці значення без редагування `app.js`. Не додавайте до `config.js` паролі, токени чи інші секрети: файл завантажується в браузер і є публічним.

### Дні народження

Дані зберігаються у `data/birthdays.json`. Формат запису:

```json
{
  "date": "MM-DD",
  "name": "Прізвище Ім’я По батькові",
  "position": "Посада або клас",
  "category": "Працівники"
}
```

Рік народження не використовується. Для тимчасового приховування запису можна встановити `"active": false`. JSON не підтримує коментарі.

**Конфіденційність:** GitHub Pages — публічний вебсайт. Файл `data/birthdays.json` можна відкрити й завантажити напряму, навіть якщо репозиторій приватний. Він містить повні імена, дні народження та посади. Публікуйте ці дані лише за наявності належної правової підстави та погоджень; за потреби приберіть блок днів народження або замініть набір даних до публікації.

### Шрифти

Статичні правила `@font-face` розміщені в `assets/fonts.css`. Файли шрифтів лежать у `assets/fonts/`. Перед публікацією перевірте ліцензійні умови: розміщення файлів у GitHub Pages означає їхню публічну доступність. Якщо право на поширення не підтверджене, видаліть файли шрифтів із репозиторію та використовуйте системний шрифт із CSS fallback.

## Як отримуються зовнішні дані

### Повітряні тривоги

Браузер напряму звертається до `https://tryvoha.online/api/v1/alerts`; резервна адреса — `https://xn--80adds5ajn.online/api/v1/alerts`. Документація постачальника вказує відкритий CORS, ліміт 120 запитів/хвилину на IP та кешування відповідей на 30–60 секунд. Тому опитування налаштоване раз на 30 секунд і використовує один загальний запит для всіх областей та районів.

Це інформаційне API, а не офіційний канал оповіщення. Дані можуть затримуватися або бути недоступними. Екран не замінює сирену, офіційний застосунок «Повітряна тривога» та розпорядження відповідальних осіб.

### Погода

Дані отримуються безпосередньо з Open-Meteo раз на 10 хвилин. API не потребує ключа для звичайного некомерційного використання й підтримує CORS. На екрані додано посилання-атрибуцію на Open-Meteo.

### Геодані

Межі областей і районів завантажуються з репозиторію `Astaryon/UA_geojson` через GitHub Raw; резервне джерело — jsDelivr. Браузер кешує відповіді. Контур України збережено локально як резервний силует.

## Важливі технічні відмінності від PHP-версії

- `api.php`, `config.php`, `fonts.php`, `index.php` і `.htaccess` вилучені: GitHub Pages не виконує PHP.
- Серверне спільне кешування з PHP-проксі замінено прямими запитами браузера та кешем браузера. Дані не кешуються централізовано між різними екранами/пристроями.
- Тривоги запитуються одним endpoint замість двох. Це знижує кількість звернень, але кожен відкритий екран робить власні запити.
- Якщо кількість одночасних екранів суттєво зросте або зовнішній API змінить CORS/ліміти, потрібен окремий JavaScript edge/serverless proxy (наприклад Cloudflare Worker) із централізованим кешем. Сам GitHub Pages такого серверного коду не запускає.
- GitHub Pages не дозволяє налаштовувати довільні HTTP-заголовки на рівні PHP/Apache; у `index.html` задано доступну для статичного хостингу CSP meta policy.

## Джерела й обмеження

- [Tryvoha.online API](https://tryvoha.online/api) — активні тривоги; обов’язкова атрибуція постачальника.
- [Open-Meteo](https://open-meteo.com/) — погодні дані.
- [UA_geojson](https://github.com/Astaryon/UA_geojson) — межі областей і районів.

Перед використанням на інформаційному екрані перевірте живі дані, районне зіставлення, карту й статус ліцею безпосередньо на опублікованому домені.
