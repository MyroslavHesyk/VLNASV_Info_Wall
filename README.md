# Військовий ліцей — інформаційний екран (GitHub Pages)

**Статична HTML / CSS / JavaScript версія V5** інформаційного екрана для телевізора в холі Військового ліцею Національної академії сухопутних військ імені гетьмана Петра Сагайдачного. **Без PHP, XAMPP, backend, npm та API-ключів.**

## Зміни у V5

- При **жовтій** і **червоній** локальній тривозі великі повідомлення **«ПЕРЕЙДІТЬ В УКРИТТЯ»**; кольоровий статус і весь блок підсвічуються.
- Перші **180 секунд від `started_at`** запроваджено повільне пульсування рамки та стрічки, індикатор і смужку часу. Немає звуку. Для старих епізодів анімація не перезапускається після оновлення сторінки.
- При невідомому `started_at` 180 секунд рахуються від **першого виявлення на відкритій сторінці**; це технічний резерв, не точний початок тривоги. При перезавантаженні сторінки він почнеться знову.
- Зменшено ризик помилкових збігів при зіставленні районів: названа область + назва району, кирилиця, транслітерація, історичне перейменування Червоноградського району. Якщо район неможливо зіставити з геометрією, показується **попередження про неповну карту**, а не вигаданий контур.
- Коли джерело даних недоступне, не показуємо «немає тривоги» без актуальної інформації. `?debug=1` виводить у Console назви незіставлених районів.
- Прибрано з екранних повідомлень фрази про «орієнтування на офіційні канали». Застереження безпеки лишається тут, у README.

## Швидкий старт на GitHub Pages

1. Створіть на GitHub **новий репозиторій**, наприклад `vlnasv-info-wall` (для тесту підходить публічний).
2. Відкрийте ZIP і **завантажте весь вміст папки проєкту** в корінь репозиторію. `index.html` має опинитися у корені, **не** у вкладеній папці. Завантажуйте папку `assets` повністю.
3. Відкрийте **Settings → Pages → Build and deployment → Deploy from a branch**. Оберіть `main` і каталог `/(root)`, натисніть **Save**.
4. Знайдіть URL сторінки: `https://ВАШ-ЛОГІН.github.io/vlnasv-info-wall/`. Публікація може зайняти деякий час.
5. На телевізорі відкрийте ту саму URL, бажано в повноекранному режимі 1920×1080.

> GitHub Pages публікує лише статичні файли і не запускає PHP. Ця версія звертається безпосередньо з браузера до API з відкритим CORS.

## Файли

- `index.html` — основна сторінка.
- `assets/app.css` — інтерфейс, статутна палітра та режими тривоги.
- `assets/app.js` — запити API, SVG-карта, погода, годинник, логіка розкладу.
- `assets/config.js` — **місто, координати, часовий пояс, навчальний розпорядок** (скопійовано з V3 на основі наданого документа).
- `assets/crest.png` — наданий герб ліцею.
- `assets/ukraine-outline.json` — резервний контур держави; районні межі завантажуються окремо.
- `assets/fonts.css`, `assets/fonts/` — підключення офіційних шрифтів (без поширення самих файлів).
- `.nojekyll` — публікація папки `assets` через GitHub Pages без обробки Jekyll.

## API і режим оновлення

| Дані | Джерело | Частота запитів |
| --- | --- | --- |
| Активні повітряні тривоги в областях і районах | [Tryvoha.online](https://tryvoha.online/api) | раз на 45 секунд |
| Поточний статус Львівської області | [Tryvoha.online](https://tryvoha.online/api) | раз на 45 секунд |
| Погода і прогноз на 5 днів | [Open-Meteo](https://open-meteo.com/) | раз на 10 хвилин |
| Межі областей / районів (адміністративний поділ 2020) | [Astaryon/UA_geojson](https://github.com/Astaryon/UA_geojson) via jsDelivr або GitHub Raw | при завантаженні сторінки, з HTTP-кешем |

API не потребують ключа в базовому режимі. Якщо браузер або мережа блокує CORS чи будь-який із сервісів, екран покаже **невідомий статус / недоступну погоду**, а не вигадану безпеку. Якщо немає доступу до GeoJSON, відображається лише резервний контур України.

Стабільність і доступність зовнішніх сервісів **не гарантовані**. Годинник і розпорядок беруть час з пристрою, але форматують його в `Europe/Kyiv`. Перевірте годинник телевізора.

## Демо-режими без справжньої тривоги

- `https://ВАШ-ЛОГІН.github.io/vlnasv-info-wall/?preview=clear` — тест, місцева тривога не активна.
- `...?preview=yellow` — жовта тривога, анімація та повідомлення про укриття.
- `...?preview=alarm` — червона тривога, анімація та повідомлення про укриття.

На демонстраційних сторінках є великий напис **ДЕМОНСТРАЦІЯ · НЕ РЕАЛЬНА ТРИВОГА**. Це тестові дані, їх не можна показувати як реальні на шкільному телевізорі.

## Розпорядок дня

Файл `assets/config.js` зберігає графіки **понеділок–п’ятниця / субота / неділя**. Використано наданий документ «Розпорядок дня ... на 2026–2027 навчальний рік». Розклад визначає поточний захід, перерву, наступний захід і відбій. Інтервали, не визначені документом однозначно, позначені як такі в назвах елементів при наведенні.

**Увага:** у графіку V3 деякі інтервали суботи й неділі були відновлені з об’єднаних клітинок таблиці, це не офіційно встановлені години. Їх збережено для сумісності з V3, треба звірити з адміністрацією перед використанням як офіційного розпорядку.

## Статутний стиль і шрифти

Статутні кольори: **Мундир** `#4D4634`, **Степ** `#6A653A`, **Золото** `#F39200`, а також чорний і білий. **Червоний** вживається тільки для безпеки — показу червоної тривоги. Основна гарнітура — **UAF Sans**.

У ZIP **немає самих шрифтів** UAF Sans / Volja: прикріплені картинки — не файли шрифтів і не свідчення ліцензії на їхнє розповсюдження. За замовчуванням CSS використовує локально встановлений UAF Sans або системний резервний шрифт. Для гарантованого відображення на телевізорі потрібно додати дозволені до розміщення WOFF2 в `assets/fonts/` і змінити `assets/fonts.css` за інструкцією в цій папці. Не публікуйте сторонні шрифтові файли без дозволу.

## Діагностика

1. Відкрийте браузер → **F12 → Network → Fetch/XHR**. Перевірте відповіді `api/v1/alerts`, `api/v1/alerts/lvivska`, `forecast`.
2. Вкладка **Console**: дивіться помилки CORS, JSON і мережевих запитів. `contentscript.js` або `ObjectMultiplex` часто стосуються розширень браузера; перевіряйте в чистому профілі.
3. Для геометрії перевірте `regiony.geojson` і `rayony.geojson`; якщо не завантажились — перевірте CDN та інтернет, або покладіть їх у папку `assets/` з назвами `oblasts.geojson` та `districts.geojson`, а в `assets/config.js` змініть `geometryLocal` на `true`. За замовчуванням локальних файлів немає, тому зайвих помилок 404 не виникає.
4. Для перевірки **локально без GitHub** запустіть у каталозі `python -m http.server 8080` і відкрийте `http://localhost:8080/`. Через `file:///` частина fetch запитів може блокуватись браузером.
5. Перевірте, що GitHub Pages увімкнено для обраної гілки, і `index.html` у корені.

Орієнтуватися на офіційні сирени й повідомлення та виконувати розпорядження персоналу. На публічному екрані **демонстраційний режим не використовувати**. Не показувати координати/маршрути БпЛА без перевіреного джерела; у V4 їх немає.

## Чому дані карти можуть відрізнятися від іншої карти

Геометрія адміністративного поділу (2020) і назви, що повертає API, не завжди тотожні. Відповідність має перевірятись за `oblast_slug` і назвою району; невстановлені відповідності не повинні довільно підсвічуватись. Статуси можуть відрізнятись також через затримку чи різні джерела. Для діагностики відкрийте `?debug=1` у браузері та вкладку **Console**. Невідображені райони перелічуються, якщо не вдалося однозначно зіставити назву з контуром.

Жива відповідь API недоступна в середовищі збірки, тому відповідність **усіх** районів на поточний момент тут не підтверджена; перед трансляцією в ліцеї порівняйте її з джерелом тривог.
