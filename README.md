# Військовий ліцей — інформаційний екран (GitHub Pages)

**Статична HTML / CSS / JavaScript версія** інформаційного екрана для телевізора в холі Військового ліцею Національної академії сухопутних військ імені гетьмана Петра Сагайдачного. **Без PHP, XAMPP, backend, npm та API-ключів.**


## API і режим оновлення

| Дані | Джерело | Частота запитів |
| --- | --- | --- |
| Активні повітряні тривоги в областях і районах | [Tryvoha.online](https://tryvoha.online/api) | раз на 45 секунд |
| Поточний статус Львівської області | [Tryvoha.online](https://tryvoha.online/api) | раз на 45 секунд |
| Погода і прогноз на 5 днів | [Open-Meteo](https://open-meteo.com/) | раз на 10 хвилин |
| Межі областей / районів (адміністративний поділ 2020) | [Astaryon/UA_geojson](https://github.com/Astaryon/UA_geojson) via jsDelivr або GitHub Raw | при завантаженні сторінки, з HTTP-кешем |

API не потребують ключа в базовому режимі. Якщо браузер або мережа блокує CORS чи будь-який із сервісів, екран покаже **невідомий статус / недоступну погоду**, а не вигадану безпеку. Якщо немає доступу до GeoJSON, відображається лише резервний контур України.

Стабільність і доступність зовнішніх сервісів **не гарантовані**. Годинник і розпорядок беруть час з пристрою, але форматують його в `Europe/Kyiv`. Перевірте годинник телевізора.

## Демо-режими без справжньої тривоги

- `https://ВАШ-ЛОГІН.github.io/vlnasv-info-wall/?preview=clear` — тест, місцева тривога не активна.
- `...?preview=yellow` — тест жовтого рівня.
- `...?preview=alarm` — тест червоного рівня / перехід в укриття.

На демонстраційних сторінках є великий напис **ДЕМОНСТРАЦІЯ · НЕ РЕАЛЬНА ТРИВОГА**. Це тестові дані, їх не можна показувати як реальні на шкільному телевізорі.

## Розпорядок дня

Файл `assets/config.js` зберігає графіки **понеділок–п’ятниця / субота / неділя**. Використано наданий документ «Розпорядок дня ... на 2026–2027 навчальний рік». Розклад визначає поточний захід, перерву, наступний захід і відбій. Інтервали, не визначені документом однозначно, позначені як такі в назвах елементів при наведенні.



## Статутний стиль і шрифти

Статутні кольори: **Мундир** `#4D4634`, **Степ** `#6A653A`, **Золото** `#F39200`, а також чорний і білий. **Червоний** вживається тільки для безпеки — показу червоної тривоги. Основна гарнітура — **UAF Sans**.

У ZIP **немає самих шрифтів** UAF Sans / Volja: прикріплені картинки — не файли шрифтів і не свідчення ліцензії на їхнє розповсюдження. За замовчуванням CSS використовує локально встановлений UAF Sans або системний резервний шрифт. Для гарантованого відображення на телевізорі потрібно додати дозволені до розміщення WOFF2 в `assets/fonts/` і змінити `assets/fonts.css` за інструкцією в цій папці. Не публікуйте сторонні шрифтові файли без дозволу.

## Діагностика

1. Відкрийте браузер → **F12 → Network → Fetch/XHR**. Перевірте відповіді `api/v1/alerts`, `api/v1/alerts/lvivska`, `forecast`.
2. Вкладка **Console**: дивіться помилки CORS, JSON і мережевих запитів. `contentscript.js` або `ObjectMultiplex` часто стосуються розширень браузера; перевіряйте в чистому профілі.
3. Для геометрії перевірте `regiony.geojson` і `rayony.geojson`; якщо не завантажились — перевірте CDN та інтернет, або покладіть їх у папку `assets/` з назвами `oblasts.geojson` та `districts.geojson`, а в `assets/config.js` змініть `geometryLocal` на `true`. За замовчуванням локальних файлів немає, тому зайвих помилок 404 не виникає.
4. Для перевірки **локально без GitHub** запустіть у каталозі `python -m http.server 8080` і відкрийте `http://localhost:8080/`. Через `file:///` частина fetch запитів може блокуватись браузером.
5. Перевірте, що GitHub Pages увімкнено для обраної гілки, і `index.html` у корені.
