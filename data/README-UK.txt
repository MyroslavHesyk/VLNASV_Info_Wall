ДАНІ ДНІВ НАРОДЖЕННЯ
=====================

Файл birthdays.json використовується інформаційним екраном для показу іменинників поточного дня.

Формат запису:
{
  "date": "MM-DD",
  "name": "Прізвище Ім’я По батькові",
  "position": "Посада або клас",
  "category": "Працівники"
}

Приклад для учня:
{
  "date": "09-14",
  "name": "Прізвище Ім’я По батькові",
  "position": "8-Б клас",
  "category": "Ліцеїсти"
}

Правила:
- Дата містить тільки місяць і день, рік не потрібен.
- `category` може бути `Працівники` або `Ліцеїсти`.
- `position` може бути посадою, класом або коротким статусом.
- Новий запис додається всередину масиву `people` через кому.
- Не додавайте коментарі всередину JSON: формат JSON їх не підтримує.
- Не змінюйте структуру ключів.
- Якщо запис треба тимчасово вимкнути, встановіть `"active": false`.
- Дані завантажуються з браузера за адресою `data/birthdays.json`.

Примітка щодо вихідного документа: один запис із датою 06-12 для Івасейка Андрія Павловича перенесено в поле `needs_confirmation` основного JSON, а не в активний список. У тому самому документі він уже зазначений з датою 06-01-1980. Публікувати обидві дати без уточнення було б некоректно.
