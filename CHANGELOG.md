# Історія змін

## Статична версія для GitHub Pages
- Перетворено `index.php` на `index.html`.
- Конфігурацію винесено в `assets/config.js`.
- Динамічне підключення шрифтів через PHP замінено на `assets/fonts.css`.
- PHP API-проксі замінено прямими CORS-запитами до Tryvoha.online та Open-Meteo.
- Геодані завантажуються з GitHub Raw із резервним джерелом jsDelivr.
- Запит тривог оптимізовано до одного endpoint раз на 30 секунд.
- Додано видиму атрибуцію джерел даних.
- Збережено карту, псевдоніми районів, погоду, дні народження, розклад, анімації та деморежими.
